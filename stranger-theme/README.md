## 🔮 Theme Variants

Stranger Things Theme comes with six unique variants, each inspired by iconic elements from the show:

### Upside Down

<p align="center">
  <img src="./assets/upside-down-preview.png" width="600" />
</p>

A dark, eerie theme inspired by the alternate dimension from the show. Features desaturated blues and blacks with occasional glowing elements, mimicking the cold, alien environment of the Upside Down.

| Palette | Hex | Purpose |
| --- | --- | --- |
| Background | `#0D1117` | Editor background |
| Foreground | `#E6EDF3` | Default text |
| Comment | `#5C6370` | Comments (low contrast) |
| Keywords | `#C678DD` | if, for, return, etc. |
| Strings | `#98C379` | String literals |
| Functions | `#61AFEF` | Function names |
| Classes | `#56B6C2` | Class/Type names |
| Variables | `#ABB2BF` | Variable names |
| Numbers | `#D19A66` | Numeric constants |
| Tags | `#E06C75` | HTML/JSX tags |

As Eleven would say: "Friends don't lie. But they do help each other code."

## 🚀 "How do I submit a new theme implementation?"

1. Create a new repository based on our template
2. Build the new theme implementation using the color palettes above
3. Submit an issue with a link to your repository
4. Once accepted, we'll move the repository under the Stranger Things Theme organization and give you rights to maintain it 🤘

## 🧠 About

The Stranger Things Theme is designed to be both visually appealing and functional. Each color palette maintains a good contrast ratio for readability while capturing the essence of the show's iconic elements.

As Chief Hopper would say: "Mornings are for coffee and contemplation... and proper syntax highlighting."
