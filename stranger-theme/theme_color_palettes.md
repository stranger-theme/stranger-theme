# Stranger Things Theme - Color Palettes for IDE Themes

Based on the Dracula Theme structure and our Stranger Things research, here are the defined color palettes for each theme variant.

## Base Colors (Common to All Variants)
These colors will be used for basic UI elements across all theme variants:

```
foreground: "#F8F8F2"  # Light text (same as Dracula for readability)
```

## Upside Down Theme
Inspired by the dark, eerie alternate dimension with blues, blacks, and desaturated tones.

```
# Primary Colors
background: "#0E1C26"        # Dark blue-black background
currentLine: "#1A2C3A"       # Slightly lighter blue for current line
selection: "#2A3C4A"         # Selection color
comment: "#4D6A87"           # Muted blue for comments

# Accent Colors
cyan: "#5CCFE6"              # Cold blue
green: "#3D7668"             # Desaturated teal green
orange: "#7D6F5D"            # Muted brown
pink: "#7B5D8F"              # Desaturated purple
purple: "#5D6FA3"            # Muted blue-purple
red: "#8F5D5D"               # Desaturated red
yellow: "#8F8C7D"            # Desaturated yellow
```
